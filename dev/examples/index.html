Examples

The tutorial and the synthetic examples simulate occultations with a known truth. Each of the other examples reduces a published occultation again, from the data given in the paper, and compares the results with the publication. The transcribed data and the stored JPL Horizons ephemerides are in examples/data/, so all examples run offline. Each writes its figures and its printed results to examples/output/<example>/.

The pages are made from the example scripts with Literate.jl: the comments of a script are the text of its page. The code is not run when the manual is built; the output after each section is that of the last run of the script.

Standard figures

Every example writes the same standard figures (examples/standard_figures.jl), next to its own:

FileContent
<name>_limb_fit.pngthe limb fit with the default display: 1σ shape band and centre ellipse
<name>_limb_fit_region.pngthe limb fit with the 68.3 % (1σ) region of whole limbs
<name>_limb_fit_paper.pngthe limb in the style of the paper's figure (band type and level)
<name>_posterior.pngthe limbs of the posterior
<name>_geomap_prediction.pngthe predicted shadow path (ephemeris only, nominal radius) with its cross-track uncertainty
<name>_geomap_postfit.pngthe shadow path reconstructed from the fit
<name>_geomap_comparison.pngboth paths together
<name>_globe.pngthe post-fit path on the globe: Earth limb, night side shaded, terminator

The results of all examples are compared with the publications in Comparison with published reductions; the fitting methods of SORA, which most of these papers used, are compared with those of this package in Occultations.jl and SORA.
